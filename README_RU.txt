PIXFORGE STUDIO — САЙТ ПРОЕКТА
===============================
Файлы:
- index.html — страница
- style.css — дизайн и адаптивность
- script.js — мелкие интерактивные детали
- assets/pixforge-icon.png — логотип (если добавлен)
- downloads/PixForgeStudio.zip — сюда поместите готовый архив программы

ПРЕДПРОСМОТР НА КОМПЬЮТЕРЕ
1. Распакуйте ZIP.
2. Откройте index.html в браузере.

БЕСПЛАТНАЯ ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Создайте бесплатный аккаунт на https://github.com/
2. Нажмите New repository, назовите репозиторий pixforge-studio-site.
3. Сделайте его Public и создайте репозиторий.
4. Нажмите Add file → Upload files.
5. Загрузите все файлы и папки из этой папки (не загружайте сам ZIP сайта вместо содержимого).
6. Нажмите Commit changes.
7. Откройте Settings → Pages.
8. В разделе Build and deployment выберите Deploy from a branch.
9. Branch: main, folder: /(root), нажмите Save.
10. Через несколько минут сайт будет доступен по адресу:
    https://ВАШ-ЛОГИН.github.io/pixforge-studio-site/

КНОПКА СКАЧИВАНИЯ
Положите готовый архив редактора в downloads/PixForgeStudio.zip и снова загрузите
обновлённую папку на GitHub. Пока файл не добавлен, сайт предупредит об этом.
Не публикуйте пароль, токены или личные данные.
